Welcome to My Library

My Library is your personal gateway to exploring books, authors, and genres in a simple, organized interface. Whether you're a casual reader or a developer looking to understand Django fundamentals, this app offers a clear, minimal design that’s easy to navigate.

This is a read-only book viewing application. All data is managed via the Django admin interface and presented here through dynamic templates and views. The focus of this project is to demonstrate:

  • Clean data presentation using Django’s templating system
  • Navigation using buttons and links across multiple pages
  • Basic use of models, views, and URLs in a Django app

Use the navigation buttons to browse the available books, meet the authors, explore genres, or learn more about this project on the About page.

Thanks for visiting, and enjoy exploring the library!
