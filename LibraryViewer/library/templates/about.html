About My Library

My Library is a simple and elegant web-based book viewer built using Django. It allows users to browse a curated list of books, authors, and genres in a clean, readable format.

This project was developed as a part of my learning journey in web development with Django. The goal was to create a lightweight application that demonstrates:

  • Model-View-Template (MVT) architecture in Django
  • Database integration with read-only access
  • Reusable templates and clean URL routing
  • Basic front-end styling using CSS and navigation with buttons

All book records, author profiles, and genre categories are stored in a database and displayed dynamically through Django views. This project does not support editing or adding books through the interface — it is strictly read-only for simplicity.

Feel free to explore the different sections of the app using the navigation buttons above. Thank you for visiting!
